# Abstract

The goal of this project is to facilitate the surfing of the indie web.

We identify indie web sites as having some/all of the following:

- intentionally designed[^1] and wholly human-authored.
- non-commercial focus.
- lacking direct affiliation with any for-profit entity acting antithetically to the ideals of free software, the right to privacy, the indominable human spirit, and a prosperous open web.[^2]

The few criteria above, while essential, are quite broad (by design).
Each of the following will increase ranking:

- **Webring(s) presence (the more the merrier)**
- **Proximity to known indie web directories / platforms (ex: Neocities, Nekoweb, Friendrewind, Smooth Sailing Listings, etc.)**
- hypertext-friendly design
- independent / Fediversal hosting
- Accessible, semantic HTML

For efficiency's sake, *we ignore any web page directly hosted on the top 1000 most visited web domains.*

[^1]: Either coded directly, using a CMS, or a website building platform (eg. Wix, Carrd).

[^2]: Indirect *hosting* is permitted *(ex: a Blogger blog)*.
